# 고교학점제 5등급제 대입 나침반

2009년생 이후 적용되는 **고교학점제 5등급제 내신·모의고사 등급 환산**, **학교별·학년·학급 석차 계산**, **전국 180개 대학 36,000개 학과 맞춤 추천**, **학교별 기출문제(상·중·하)** 및 **AI 강사 판서 그림 요약 노트북**을 한곳에 모은 대입 설계 웹 애플리케이션입니다.

## 주요 기능

1. **성적 목표 미션 · 군대 계급 성장 & 기출 토큰 시스템**
   - 내신 시험(1·2학기 중간/기말) 또는 모의고사(3·6·9·10모·수능)별로 **목표 평균 등급**, **전체 학년 석차 목표**, **전체 학급 석차 목표**, **각 과목별 등급·석차 목표**를 세분화해 설정하고 실제 성적·석차와 비교 판정
   - **목표 도달 성공**: **군대 계급 1단계 진급 (`이병` → `일병` → … → `대장` 총 18계급)** + **기출 문제 풀이 토큰 2개 지급**
   - **미션 실패 시 재도전 루프**: 미달 항목을 기록한 뒤 다음 목표를 다시 정해 목표에 도달할 때까지 반복 도전
   - **토큰 기반 기출 제한**: 보유 토큰 1개당 기출 1문제를 풀고 채점·해설을 확인할 수 있어(2토큰 = 2문제 풀이), 목표 달성과 기출 풀이를 선순환 구조로 연결

2. **내신·모의고사 분리 환산 및 학년/반 석차 산출**
   - 출생연도별 자동 판별: **2008년생(고3) 9등급제** vs **2009년생 이상 5등급제 → 9등급제 정밀 환산**
   - **2단계 내신 시험 선택**: `1학기 / 2학기` × `중간고사 / 기말고사` 분리 입력 및 환산 (`정보`는 1학기 기말고사 전용, `인기초(인공지능 기초)`는 2학기 기말고사 전용 자동 반영) + 과목별 실제 석차 입력 지원
   - **모의고사 시험 선택**: `3모`, `6모`, `9모`, `10모` (고3은 `수능` 포함) 시험별 분리 입력·저장
   - **학교별 학년 석차 & 반 등수 계산**: 목포덕인고(1학년 183명, 1~7반 정원) 등 학교 편제 반영, 인원 직접 수정 및 실제 전교·반 등수 입력·역산기·등급별 석차 커트라인 표 제공

3. **전국 180개 대학 · 36,000개 학과 탐색 및 고교 진학 통계**
   - 선택한 내신 시험 또는 모의고사 기준으로 지원 가능 대학(안정 / 적정 / 상향) 즉시 분석
   - 36,000개 학과 카탈로그 검색, 학과 설명·권장 선택과목·재학 고교 진학 추정 인원 표시

4. **학교별 기출문제 (상·중·하) · 교과서 출판사 선택 & AI 강사 그림 요약 노트북**
   - 학교·과목·학기·고사·**교과서 출판사**(비상교육, 미래엔, 천재교육, 좋은책신사고, 창비, NE능률, YBM 등 + 직접 입력) 및 **기출 난이도(`전체`, `하`, `중`, `상`)** 필터링과 토큰 기반 객관식 즉시 채점·서술형 채점 기준 제공
   - **시험 범위 및 출판사 입력**을 통해 해당 교과서 단원에 맞춘 **AI 강사 맞춤 기출 출제** (`/api/study/generate-exam`) 및 **판서 도해 그림이 포함된 줄노트북 요약 노트** (`/api/study/generate-note`) 생성

5. **생기부·세특 및 선택과목 공부법 가이드**
   - 고1·고2·고3 수준별 실행 체크리스트, 계열별 세특 탐구 주제 예시, 선택과목별 공부법 및 대학별 권장과목 매트릭스 제공

## 기술 스택

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React
- **Backend**: Node.js (v22+), Express, `@google/genai` (서버 사이드 Gemini API 연동)

## 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. 환경 변수 설정

`.env.example`을 참고하여 `.env` 파일을 생성합니다.

```env
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
```

### 3. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

### 4. 타입 검사 · 프로덕션 빌드 · 실행

```bash
npm run lint
npm run build
npm start
```
